# Etemad Melal — Investment Panel Case Study

A front-end case study for **Etemad Melal**, a Persian-language investment platform built with **Next.js** and **React**. Covers both the user-facing panel (dashboard, deposits, withdrawals, package purchase) and the admin back office (analytics, referral tree, approval workflows, support tickets).

**Live:** https://etemadmelal-case-study.vercel.app/

## Role
Front-End Developer (solo) — Feb 2025 – Present, Contract

## Stack
- Next.js / React
- REST API integration
- Persian / RTL layout
- Dark & light theme system
- Chart-based data visualization
- Role-based access control (RBAC)

## About this repo
This is a static, single-file HTML case study (screenshots + write-up), not the platform's source code — the platform itself is closed-source client work. Built to walk through the product, my contributions, and the front-end decisions behind it.
